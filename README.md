# SamuelFrutas App Updates

Central público de atualizações dos aplicativos SamuelFrutas.

Os códigos-fonte permanecem nos respectivos repositórios privados.

## Canais

- `apps/rotina-certa/latest.json`: informações da versão mais recente do Rotina Certa.
- Cada aplicativo terá seu próprio manifesto e suas próprias versões.

Os APKs publicados aqui são somente arquivos de instalação. Atualizações Android sempre dependem da confirmação do usuário no aparelho.
